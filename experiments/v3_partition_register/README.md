# V3 — dedicated partition register controls

`uv run rcp-qi-register --min-n 2 --max-n 6` measures reduced density matrices, left/right-target trace distance, and data-partition probabilities for label-before, label-after, and phase-kickback circuits. No additional readable partition information was found **in these controls**. The `local_partition_diffuser` applies `_diffuse(circuit, [n - 1])`, a partition-bit-only reflection, not diffusion inside both blocks. Its negative result does not apply to Grover–Radhakrishnan partial search. The physical gate and ancilla costs of the historical controls are recorded.
