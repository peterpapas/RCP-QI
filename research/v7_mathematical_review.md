# V7 mathematical review: transformations before operators

**Status (26 November 2026):** theorem-driven characterization and literature review. No V7 quantum circuit or V8 operator was implemented. The existing V1–V3/V6 tests constrain their specified unstructured circuits; V5/V5.1 are classical controls. V5.1 found no observed crossover over direct CDCL under its two-seed, two-second protocol. None of these observations is a universal quantum lower bound.

## Model and the question that matters

Let `X={0,1}^n`, `f:X→{0,1}`, and `G(S)=∨_{x∈S} f(x)`. A relation `T`, group action, quotient `q:X→Y`, or constraint parameterization must be part of the input promise **or** discovered from the instance. Count discovery, certification, representative computation, reversible compilation, state preparation, oracle evaluation, inverse/uncomputation, measurements, repetitions, final verification, and failed attempts. An oracle that directly returns `G(S)` changes the input model unless it is built and charged from `f`.

The architecture need not survive this review. If a useful relation leads to a walk, Fourier procedure, or direct classical solver instead of recursive halves, use that method. A transformation is a computational advantage only if its *total* cost improves on the strongest equally informed baseline, not merely an arbitrary prefix search.

## Proven and derived characterizations

1. **Conditional Lean theorem: a total complementing map trivializes witness search classically.** If `f(Tx)=1−f(x)` for every `x` and some `x₀` can be produced, evaluate `f(x₀)` once. Return `x₀` if true and `T(x₀)` otherwise. `complementing_one_query_witness` formalizes correctness; the theorem assumes `T` and its law, and does not bound their discovery or evaluation costs. Involution is unnecessary for this witness result. If `T²=id`, every orbit is a true/false pair; for a unique solution and `|X|>2`, such a total map is impossible by the existing Lean pair theorem. A partial map needs an explicit covered domain and a way to reach it.
2. **Conditional Lean equivalence: preserving quotient.** For a known surjection `q:X→Y` with section `r:Y→X`, `f` factors as `g∘q` exactly when it is constant on every fiber of `q`. `factor_implies_fiber_constant` and `fiber_constant_factors` prove both directions for a supplied section; `g(y)=f(r(y))`. `quotient_existence_equivalence` proves `∃x f(x)=1 ↔ ∃y g(y)=1`. Each query to `g` can be simulated by one query to `f` at `r(y)` and each query to `f` by one to `g` at `q(x)`, *provided* `q,r` are available and their costs are charged. This is an oracle-access equivalence, not an unconditional runtime equivalence or a proof that any quotient is easy to find.
3. **Derived black-box condition.** If the quotient verifier `g` is otherwise an arbitrary function on `M=|Y|` labels, its unique-marked search is still unstructured: bounded-error quantum query cost is `Θ(√M)` and classical query cost is `Θ(M)` in the usual oracle model. This follows by the query simulation above plus the standard search lower bound [BBBV](https://arxiv.org/abs/quant-ph/9701001); the lower bound is external, not formalized in Lean. A cheap quotient can beat Grover over `|X|` by reducing the domain, but the same quotient helps classical search. A genuinely new quantum mechanism requires additional usable structure in `g` or a stronger stated oracle model.
4. **Derived recursive limitation.** A root SAT test followed by one existence decision per bit makes `n+1` calls for a satisfiable `n`-variable instance (`root_plus_recursive_call_count` in Lean). If a bounded-error recursive black-box algorithm found the unique marked item using `o(√|X|)` total calls to `f`, it would contradict the unstructured search lower bound. This says nothing about structured SAT with an explicit clause representation. Call count alone does not order wall times against incremental CDCL.
5. **Derived Walsh counterexample for a unique marked item.** Set `F(x)=(-1)^{f(x)}=1−2·1[x=w]`, `N=2^n`, and normalized Walsh coefficient `F̂(s)=N⁻¹∑_x F(x)(−1)^{s·x}`. Then `F̂(s)=1[s=0]−(2/N)(−1)^{s·w}`. A single `H^⊗n U_f H^⊗n` measurement therefore has probability `(1−2/N)²` at zero and `4/N²` at each nonzero `s`, **independent of `w`**. The phase contains `w` but this measurement erases it. This rules out one naive Fourier sample as a partition locator; it does not rule out all coherent interference procedures. If `T(x)=x⊕d` complements validity, `F̂(s)` vanishes whenever `s·d=0`; that spectral support still does not identify a witness and the supplied `T` already yields one classical-query search.
6. **Conditional Lean reduction: semantic symmetry certification can be as hard as UNSAT.** Given any CNF `H(x)`, form the CNF `F(x,b)=b ∧ H(x)` and supply the explicit transformation `T(x,b)=(x,¬b)`. Then `F(T(x,b))=F(x,b)` for every `(x,b)` **if and only if** `H` is unsatisfiable. `gated_flip_preserving_iff_unsat` proves the Boolean equivalence; the mapping adds one variable and one unit clause. Since CNF UNSAT is coNP-complete, semantic certification of even a supplied bit-flip validity-preserving transformation is coNP-hard in general. This does not make *syntactic CNF automorphism* certification hard: checking that a supplied variable permutation preserves the signed clause multiset is a narrower polynomial test.

The Walsh probability equation is independently checked by a small NumPy/SciPy Hadamard-matrix test for `n=2..6` and several target positions in `tests/mathematical/test_v7_walsh.py`. This is a numerical check of the derivation, not a Lean proof or hardware experiment.

Two counterexamples prevent overinterpretation. `f(x,b)=b XOR H(x)` has a known bit-flip complement for *any* Boolean `H`, yet finding a witness is trivial because the added bit can be chosen after one evaluation. `f(x,z)=H(x)` with free dummy variables `z` has large validity-preserving orbits and a quotient that removes all `z`; deciding it is still as hard as deciding the arbitrary core `H`. Adding apparent complementarity or symmetry does not make the underlying family genuinely hard in the desired way.

| --- | --- | --- | --- |
| **Validity complement** `f(Tx)=1−f(x)` for all `x` | A supplied `T` can be checked syntactically for certain affine/CNF forms; checking an arbitrary semantic identity can itself hide hard reasoning. Count `C_T` and certificate. | One `f` evaluation plus one `T` application gives a witness. Unique-solution spaces larger than two cannot admit a total complementing involution. | No search advantage over the same supplied relation classically. An affine parity example is tractable; no general 3-SAT promise. |
| **Validity preservation** `f(Tx)=f(x)` and certified group generators | A proposed variable permutation can be checked on the signed clause multiset; finding useful generators, a canonical representative and a small quotient can be costly. Full symmetry breaking may require many predicates. | One test applies to its whole orbit; quotient search works classically. Symmetry-aware CDCL and orbit representatives are baselines. | Grover over a cheap quotient gives standard amplification on a smaller domain. A new benefit needs a coherent group operation with total cost below this baseline. Symmetry does not imply tractable SAT. |
| **Orbit/quotient** `f=g∘q`, known section `r` | Certify fiber constancy and implement `q,r`; a supplied section is an additional promise. | Search over `|Y|` labels; one oracle query translates in either direction. | Generic `g` retains the `√|Y|` quantum bound. Plausible only if `g` has extra exploitable algebraic structure or unusual representation. |
| **Hidden shift** `h_s(x)=h(x⊕s)` with known `h` and coherent access to shifted `h_s` | The pair of function oracles and shift promise are inputs; deriving them from a SAT CNF is an unproved reduction. Reversible `h`, `h_s`, and any dual must be charged. | Classical hidden-shift query complexity depends on `h`; for a delta function this is ordinary marked-item search. | Bent-function and some other promised shifts have known quantum advantages. This is **shift recovery**, not SAT existence; it is a precise oracle-model control worth studying only if a solution-preserving reduction with no hidden witness encoding is found. No such reduction is known here. |
| **Constraint-preserving subspace** known parameterization `e:Y→S⊆X` for easy constraints `C` | Derive and compile `e`, prepare `|S|` superposition, and reflect/uncompute. Preparing the satisfying subspace of the *whole* formula would hide the goal. | Enumerate/branch only in `S` and solve the residual constraints `D` directly. GF(2) elimination and 2-SAT SCC are tractable controls. | Standard amplitude amplification searches residual solutions in `S`; feasible-subspace mixers have precedent. An NP-hard residual family needs a theorem on state-preparation and marking cost before a new claim. |
| **Boolean Fourier structure** accessible large coefficients or dual | Derive a spectrum promise from syntax or estimate it with charged samples/queries; benchmark classical Fourier-learning and algebraic simplification. | Fourier coefficients can reveal parity and hidden-shift structure, but a unique delta marker has flat nonzero measurement probabilities independent of location. | Bernstein–Vazirani is an existing parity-oracle query separation, while explicit affine constraints are classically solvable. A useful SAT-specific Fourier signature and efficient reversible access are unproved. |
| **Residual-subproblem relation** between branches | Prove a transformation maps residual CNFs and preserves/negates validity; scoring correlations alone are insufficient. | CDCL learning, unit propagation, symmetry breaking and direct solving already reuse structure. | Could motivate coherent backtracking or a quantum walk, but must beat Montanaro/MNRS costs with actual reversible update/check operations. No current certificate supplies such a relation. |

## Necessary and sufficient conditions, with scope

For a **known quotient** with a section, fiber constancy is necessary and sufficient for *value-level factorization* through `q` (Lean). To improve over full-space generic Grover on a unique-solution promise, a sufficient **cost inequality** is `C_discover + C_certify + C_compile + C_setup + R[Θ(√M)·(C_mark + C_reflect + C_uncompute) + C_measure] + C_verify < C_full_Grover`, where `C_reflect` includes any repeated preparation and inverse and `R` is the number of attempts needed for the target success probability. `C_full_Grover` must be costed with the same gate, oracle, error and verification model. This is a design criterion, not an observed inequality. To improve over classical methods, compare also with direct CDCL, symmetry-aware CDCL, dedicated family algorithms and classical quotient search; no quotient-size condition alone is sufficient. In a black-box model with no exploitable promise beyond a generic unique marker, an `o(√N)` total-query partition method is impossible by the standard search bound.

These conditions cannot prove a general time lower bound for explicit NP-hard SAT. They identify where the input model or structural promise must differ. A recognized structural family can still be NP-hard: the free-dummy symmetry construction reduces arbitrary SAT to a symmetric family. Conversely, XOR-SAT and 2-SAT are polynomial-time controls. Hidden-shift promise problems must not be relabeled NP-hard without a reduction.

## Operator design gate: evaluated

| Candidate | Definition and predicted information | Full cost and matched baselines | Decision |
| --- | --- | --- | --- |
| Complement-pair phase | A supplied `T` flips `f`; Fourier support can move to characters odd on the flip mask. | Discovery/certification, `T`, phase oracle, transforms and shots versus one classical `f` evaluation plus `T`. | **Reject for witness search:** classical one-query theorem defeats a quantum-specific claim. |
| Known-orbit quotient | Prepare/reflect over one representative per orbit and mark via `f(r(y))`; predicts standard Grover success on `M` labels. | Group discovery, canonicalization, representative state preparation, inverse, `√M` markings versus classical quotient search and symmetry-aware CDCL. | **Defer:** this is Grover on a preprocessed domain; no additional interference mechanism or proved favorable total-cost bound. |
| Hidden-shift Fourier operator | Under `h_s(x)=h(x⊕s)` and suitable spectral promise, interference can recover `s`. | Two oracle constructions, dual/known `h`, coherent queries, state prep, measurements, certification versus established hidden-shift algorithms and classical shift recovery. | **Research control only:** known quantum mechanism, but no reduction from a meaningful SAT family with costs. |
| Constraint-aware mixer/walk | Mix only inside a certified feasible subspace or backtracking tree. | Derivation, reversible setup/update/check, reflection, ancillas and error control versus direct CDCL, constrained classical search, Grover/amplification and quantum backtracking. | **Defer:** no theorem that the resulting walk or mixer improves those baselines on a specified hard family. |

**Falsifiable next hypothesis:** find a polynomial-time certifiable family `𝓕` and quotient/subspace map whose residual verifier has a specified nontrivial spectrum or walk gap, with reversible construction and an upper bound on total quantum cost strictly below matched classical and quantum baselines. Failure to find such a family leaves the quotient equivalence and complement-triviality characterizations as the V7 result. No candidate above passes the operator gate, so Phase D circuit experiments are not authorized by the mathematical evidence.

## Research direction

**Architecture decision:** abandon total complement pairing as a witness-search advantage under equal access to `T`; suspend generic recursive half selection because no cheaper existence primitive is established; retain quotienting only as a costed preprocessing idea available to classical and quantum solvers. Interference remains a possible technique under a certified spectral, shift or walk promise, not an objective by itself.

Prioritize counterexamples and reductions over more prefix tuning. Test whether proposed structural promises survive removal of free variables, tautologies, and explicit witness encodings; then prove which residual problem remains hard. For a surviving candidate, specify the algorithm's input representation and a certificate before measuring interference. Seek a formal oracle-access reduction or impossibility result when a stronger mechanism cannot be established. Preserve V1–V6 and V5.1 as historical controls. The precise Lean scope is recorded in [formal status](../theory/formal_status.md), and original literature is linked from the [literature review](literature_review.md).

The successor [V7.1 structural promise investigation](v7_1_structural_promise_discovery.md) extends the analysis to local complementarity, affine/nonlinear residuals, quadratic systems, Simon/Shor promises and constraint hypergraphs. V8 remains suspended.
