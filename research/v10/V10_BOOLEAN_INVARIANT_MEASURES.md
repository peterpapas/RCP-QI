# Boolean-invariant measure screen

Fix a finite Boolean function `f:{0,1}^m→{0,1}`. All measures below are unchanged when two *representations* compute the same `f`, provided the input-bit labels, field/basis, split, error and promise are held fixed. That mathematical invariance says nothing about extraction from a succinct CNF. For a SAT verifier, the `m` bits are **candidate-assignment bits**; for a SAT-decision algorithm, the input bits encode the **formula**. A query lower bound in the former model is not an explicit-input SAT time bound.

| Measure and definition | Model / bound direction | Obtaining it from an explicit CNF; structural use and limitation |
| --- | --- | --- |
| Exact multilinear degree `deg(f)`: degree of the unique real multilinear extension | Polynomial/decision-tree query lower bound `D(f)≥deg(f)`; also can upper-bound via explicit polynomial evaluation only with charged representation | Full truth-table interpolation is exponential in `m`. `AND_m` has degree `m` but its satisfying assignment is immediate. Field must be fixed for algebraic degree. |
| Approximate degree `~deg_ε(f)`: least real polynomial degree with pointwise error ≤`ε<1/2` | Bounded-error quantum bit queries `Q_ε(f)≥~deg_ε(f)/2` by [Beals et al.](https://arxiv.org/abs/quant-ph/9802049); no general gate/time inference | A succinct CNF does not supply the approximant or dual witness. A dual certificate may prove a bound if independently verified; formula-access model differs. |
| General adversary `Adv±(f)`: maximum spectral ratio over matrices zero on equal-output input pairs | Quantum **query** lower bound and, with its hypotheses, tight characterization; [Høyer–Lee–Špalek](https://arxiv.org/abs/quant-ph/0611054), [Reichardt et al.](https://arxiv.org/abs/1011.3020) | Analytic witness can be compact on symmetric promises; general matrix dimension follows the oracle-input family, not the CNF length. |
| Certificate complexity `C(f)=max_x min{|S|:fixing x_S fixes f(x)}` | Classical bit-query lower-bound ingredient and upper bound on nondeterministic certificate length, not SAT time | A satisfying assignment is an NP witness for SAT-decision, a different certificate notion. Exact worst-case `C(f)` is not supplied by CNF syntax. |
| Sensitivity `s(f)=max_x |{i:f(x)≠f(x⊕e_i)}|`; block sensitivity `bs(f)` maximizes disjoint sensitive blocks | Boolean-query complexity measures; polynomial relationships for total functions, including [Huang's theorem](https://arxiv.org/abs/1907.00847) | Easy examples can have large sensitivity. No inexpensive CNF-wide computation or quantum gate bound follows. |
| Deterministic `D(f)` and bounded-error randomized `R_ε(f)` decision-tree depth | The exact/minimum worst-case number of bit probes; upper and lower query benchmarks | Definitional optima, generally not an efficiently obtainable feature of a succinct CNF. They measure oracle truth-table-bit access, if that is the stated input. |
| Fourier sparsity `|{S:hat g(S)≠0}|` and spectral norm `Σ_S |hat g(S)|` for `g=(-1)^f` on the uniform cube | Representation-independent Fourier measures; may support specialized learning, communication or query theorems only when hypotheses match | Full Walsh transform has `2^m` coefficients. A low-sparsity **certificate** needs explicit support/coefficient verification; a CNF does not provide it free. |
| Communication matrix `M_f(u,v)=f(u,v)` for a fixed input split; real rank and `ε`-approximate rank (`|A-M|≤ε` entrywise) | `log₂ rank(M)` lower-bounds deterministic communication; approximate rank relates to selected bounded-error communication models with convention-dependent bounds | Matrix has `2^m` entries. Fixed split and distributed ownership matter. High rank can coexist with trivially satisfiable public CNF (equality-pair example). |
| Sign rank: minimum real rank with the same strict sign pattern as `(-1)^{M_f}` | Unbounded-error communication, e.g. [Forster](https://www.sciencedirect.com/science/article/pii/S0022000002000193); not automatically bounded-error or SAT-time | Sign pattern and split must be fixed. A rank certificate for a particular representation need not certify minimum sign rank. |

**Survival test:** The only plausible use is a theorem about a measure of an explicitly defined input/output function plus a certificate whose production and checking fit the claimed budget. V10 found no measure that both (i) is efficiently certified from arbitrary explicit CNF and (ii) yields a new lower bound or quantum advantage for general SAT. This is a bounded negative assessment, not a proof such a measure cannot exist. [Nisan–Szegedy](https://web.vu.lt/mif/s.jukna/boolean/Nisan-Szegedy.pdf) and [Beals et al.](https://arxiv.org/abs/quant-ph/9802049) are primary sources for the degree/query relationships.
