# Quantum information extraction: access models first

## Standard oracle and controlled extensions

For a hidden marked set `S⊆[N]`, the standard query returns `f_S(x)=1[x∈S]` coherently (or its equivalent phase query with a controlled-use convention specified). Interquery unitaries may depend on public promises/certificates but not on `S`. Success means a bounded-error output under every allowed `S`, with all queries counted. V9's unique-marker balanced-half label costs `Θ(√N)` queries by an all-ones cross-half adversary witness. The theorem is **about oracle queries**; reversible compilation from explicit CNF, state preparation, measurement, repetition and verification are separate costs. Standard [BBBV hybrid](https://arxiv.org/abs/quant-ph/9701001), [quantum polynomial](https://arxiv.org/abs/quant-ph/9802049) and [general adversary](https://arxiv.org/abs/quant-ph/0611054) methods are the relevant lower-bound tools. Composition theorems require a precisely specified composed oracle function and cannot be invoked from a clause graph alone.

| Change to model | Precise outcome |
| --- | --- |
| `t>1` marks, possibly in both halves | “The correct half” is undefined without a rule. The output can instead be `(G_L,G_R)` or a promised all-in-one-half label; these are different problems. |
| Exactly `t` marks all in one half, `t` divides `N/2` | Grover gives `O(√(N/t))` queries to find one mark and report its half. Partition `N` addresses into `N/t` public blocks of size `t`; restrict to instances with one fully marked block. A candidate query then simulates one unique-block oracle query. V9's adversary calculation yields `Ω(√(N/t))` for this subclass, hence `Θ(√(N/t))` for the stated promise. This is a direct known-search reduction, not novelty. |
| Supplied list of `K` possible target addresses, balanced across halves | The same argument gives `Θ(√K)` membership queries if the unique marker is otherwise arbitrary in the list. Printing, checking and preparing the list cost at least its representation/preparation cost; if advice reveals the half, the label is already known. |
| Direct oracle `G(A)=1[S∩A≠∅]` for requested partitions | Under a unique marker, one query for the left half returns its label. This is a **strictly richer oracle**. Constructing it from `f_S` on arbitrary sets incurs search-scale verification queries in the black-box model; assigning it unit cost hides the central difficulty. |
| Explicit formula preprocessing | The algorithm can inspect clauses and may solve or simplify the instance. Black-box lower bounds cease to cover that extra access; account for input reading, certificate production, reversible implementation and classical baselines. |
| Richer clause-violation, gradient, Fourier or witness-bearing oracle | Define the output register and construction circuit. It can reveal more than validity and may encode a witness or an NP-hard preprocessing step. No lower/upper transfer is claimed without a reduction. |

For a fixed pair of hidden cases, output-state trace distance bounds distinguishability; repeating a weak measurement cannot be assumed free. The density matrices, priors, number of coherent queries, error and any postselection probability must be specified before claiming an information advantage. Boolean-equivalent verifier expressions give the same literal diagonal phase action (V9 Lean); they cannot be separated by an oracle algorithm given only that action. A global sign distinction depends on whether controlled access is allowed.

**Stopping result for T1/T6:** candidate-list advice and block-mark promises reduce to established search, while a direct partition oracle changes the access model. No efficiently obtainable CNF certificate was found that yields a new quantum-specific information-extraction theorem with complete costs. This is a research-screen result, not a universal impossibility theorem.
